--------------------------------------------------------
1. Introduction
--------------------------------------------------------
The objective of this project is to integrate three main graph algorithms
to model task scheduling in a Smart City / Smart Campus environment:
1. Strongly Connected Components (SCC) detection using Tarjan’s algorithm.
2. Topological Ordering for DAGs derived from SCC condensation.
3. Shortest and Longest Path computations for task scheduling over DAGs.

The system simulates dependencies between city service tasks such as
maintenance, street cleaning, and sensor/camera repairs.

--------------------------------------------------------
2. Objectives
--------------------------------------------------------
1. Detect cycles in the task dependency graph and compress them into SCCs.
2. Build a condensation graph (DAG of SCCs) for acyclic scheduling.
3. Compute topological order for task execution planning.
4. Find shortest paths (minimum duration) and longest paths (critical path) in DAGs.
5. Generate multiple test datasets (small, medium, large) to evaluate performance.

6. Analysis
--------------------------------------------------------
- TarjanSCC efficiently identifies cycles and compresses them into SCCs.
- Condensation + Topological Sort ensures valid task execution order.
- DP-based DAG shortest paths minimize scheduling times.
- Longest path analysis identifies critical tasks (bottlenecks).

Performance decreases slightly with dense graphs due to more relaxations,
but overall remains linear with respect to O(V + E).

--------------------------------------------------------
7. Conclusions
--------------------------------------------------------
- SCC detection is essential for cyclic dependencies.
- Topological sorting ensures tasks are executed in the correct order.
- DAG shortest/longest path algorithms provide optimal and critical scheduling insights.
- Recommended to always run SCC compression before scheduling.
